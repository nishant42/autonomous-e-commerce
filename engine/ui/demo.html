What is automatic, and where is the AI?

The shop is the existing Medusa application. The adapter imports its orders and stock. Deterministic engines calculate demand, quantities, ad rules and product diagnoses. Tool-using language-model agents can investigate and choose validated actions. If a model fails, rules take over; KILL and larger actions wait for approval.

This screen evaluates the current rules when refreshed. Replay shows a stored run, including its original mode and timestamp. It does not claim that an AI agent is running now. Advertising data is simulated. The current local model replied during testing but failed the required tool-read check, so that tested decision used the rules fallback.
