Deep dive H · Cost model and optimisation

Tokens are the smallest line on the bill

A common assumption is that "AI company" means "LLM bill". With a deterministic-first design, model routing and caching, LLM tokens are single-digit percent of platform run cost. Most of the money goes to reliable infrastructure and bought SaaS. That is the right shape: we pay for correctness, not for tokens.

The $200-500 budget line adds headroom for peaks (Black Friday runs about 3-5× volume), retries, evaluation runs, and the hidden reasoning tokens these models bill as output. Using Claude Sonnet via Foundry ($3 / $15) as the frontier model instead would raise the total to about $320/month.

How cost is controlled

Design levers (biggest effect)

  • Deterministic first. Forecasting, allocation, reconciliation and refund decisions use no LLM tokens at all.
  • Model routing. About 84% of calls go to small or mid models. The frontier model takes about 16% of calls (procurement and panels) and about 60% of token spend, which is where the reasoning value is.
  • Escalate, don't default. Small-model extraction goes to the frontier model only when confidence is low.
  • Verifiers where they pay. T2, money fields and customer text are always verified; everything else is sampled.

Runtime levers

  • Prompt caching. Stable prefix first (instructions, then tool schemas), dynamic context last. Cached input tokens are billed at a steep discount.
  • Context budgets. A light reference on follow-up turns; tool results truncated for the model with full data kept by resultId; memory compressed to summary and facts.
  • Batch APIs for overnight, non-urgent work (catalogue refresh, Auditor sampling, evaluations), at a lower price.
  • Semantic cache at the AI gateway for repeated FAQ-style lookups.
  • Hard quotas per agent per day at the gateway, plus cost-per-task anomaly alerts in the Sentinel.

Infrastructure levers

  • Scale-to-zero for adapters, RPA and batch; KEDA scaling on queue depth.
  • Reserved capacity or savings plans for Postgres and Service Bus once the baseline is stable (typically 30-40% off).
  • Log sampling and retention tiers; PII-free, low-volume LLM content capture.
  • Ephemeral preview environments per branch, destroyed on merge.

Unit economics we track

  • Platform cost per order and per € of GMV.
  • LLM cost per resolved ticket, per supplier document, per PO.
  • Cost per agent per version: a new version must not raise cost per task by more than 15% without matching quality gains (an evaluation gate).
